# odilsho-portfolio

Personal portfolio of **Odilsho Karamalishoev** — Frontend Developer (React · Next.js · TypeScript · Tailwind CSS).

Live: https://odilsho-portfolio.vercel.app

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

All content lives at the top of `app/page.tsx` (`PROFILE`, `PROJECTS`, `EXPERIENCE`, `STACK`).
Set `PROFILE.linkedin` to show the LinkedIn icon; set `live` / `github` on a project to show its buttons.
The CV is served from `public/Odilsho_CV.pdf`.

## Deploy

```bash
npx vercel --prod --yes
```
